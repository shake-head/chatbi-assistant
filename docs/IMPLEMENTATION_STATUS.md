## 明确限制

- Docker Desktop、WSL2、Compose 已安装并完成容器验证；生产仍需固定镜像 digest、镜像扫描和可信 Registry。
- 单机 SQLite/文件存储，非多实例方案。
- SSE 是分析阶段进度流，不是模型 token 流。
- 本地规则模型是开发兜底，不等于生产模型准确率。
- 没有邮箱验证、密码找回、刷新 token、token 吊销、MFA。
- 结果缓存未启用，避免多轮上下文和权限误复用。
- 压测、真实模型评测和灰度需在实际基础设施上执行。
