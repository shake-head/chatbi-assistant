# AI 数据分析助手 · 使用手册

这是一份给「不写代码的人」看的使用说明。你只要会：**打开网页 → 上传表格 → 用中文提问**，就能得到图表、数据表和人话结论。

---

## 1. 这个工具是干嘛的

你把 Excel 或 CSV 表格传上去，然后用中文问问题，比如：

> “近 6 个月各区域的销售额趋势如何？”

它会自动给你：

1. **图表**：柱状图、折线图或饼图
2. **数据表**：算好的明细数字
3. **结论**：一句人话，告诉你结果是什么意思

你不需要会 Excel 公式、透视表，也不需要写 SQL。

---

## 2. 打开网址（推荐：中文操作台）

启动后，直接用浏览器打开：

- 中文操作台（推荐）：<http://127.0.0.1:8000/>
- 健康检查：<http://127.0.0.1:8000/health>
- 接口文档（开发者）：<http://127.0.0.1:8000/docs>

如果没有启动，用这个命令启动（在 `E:\workspace2` 目录下）：

```powershell
docker compose up -d
```

### 用操作台完成一次分析

1. **注册 / 登录**：首次打开点「注册」，填写邮箱和至少 8 位密码。
2. **上传数据**：进入「数据集」，点击或拖入 CSV / XLSX / XLS 文件，等待状态变为「可分析」。
3. **中文提问**：进入「数据问答」，选择数据集后输入问题，即可得到图表、数据表和结论。
4. **查看历史与用量**：通过左侧导航进入「历史对话」和「我的用量」。

> 下面第 3–13 节是面向开发者的接口调试方式。普通用户使用上面的操作台即可，无需继续阅读。

---

## 3. 接口调试方式：三步走

### 第 1 步：注册账号

在 `/docs` 页面里：

1. 找到 `POST /auth/register`。
2. 点它，再点右上角 **Try it out**。
3. 填邮箱和密码（密码至少 8 位）。
4. 点 **Execute**。
5. 返回结果里有一个 `access_token`，**复制它**。

> 密码别用真实常用密码，测试随便设一个即可。

### 第 2 步：登录（相当于“告诉系统你是谁”）

1. 页面最上面点 **Authorize** 按钮。
2. 在框里粘贴：

   ```text
   Bearer 你的access_token
   ```

   注意：`Bearer` 和 token 之间有一个空格。

3. 点 **Authorize** 确认。

完成这一步后，你就有权限上传表格和提问了。

### 第 3 步：上传表格

1. 找到 `POST /datasets`。
2. 点 **Try it out**。
3. 在 `file` 处选择要上传的 `.csv` 或 `.xlsx` 文件。
4. 在 `name` 处给这个表起个名字，例如 `销售数据`。
5. 点 **Execute**。

上传后会返回一个编号，例如 `id = 1`。

### 返回结果在哪里看？

点完 **Execute** 后：

1. 页面会自动往下滚到 **Responses** 区域。
2. 找到 **Server response** 下面的 **Response body**。
3. 里面是一段类似这样的内容：

   ```json
   {
     "id": 1,
     "name": "销售数据",
     "status": "parsing",
     ...
   }
   ```

4. 第一行那个 `id` 就是表格编号，比如这里就是 `1`。

### 如果没看到 id 怎么办？

直接看你的表格列表：

1. 找到 `GET /datasets`。
2. 点 **Try it out**。
3. 点 **Execute**。
4. 返回的 `items` 里每一项都有 `id`，找到刚才上传的名字即可。

> 如果返回的是 `code` 和 `message`，说明上传没成功。把 `code` 和 `message` 发出来，我帮你判断。

> 项目里已经准备了一个示例文件：`examples/sales_demo.csv`，可以直接用它练习。

---

## 4. 上传后等它“准备好”

上传是后台处理的，需要几秒钟。

查看是否准备好：

1. 找到 `GET /datasets/{dataset_id}`。
2. `dataset_id` 填你的编号，例如 `1`。
3. 点 **Execute**。
4. 看到 `status` 变成 `ready`，就说明可以提问了。

如果还是 `parsing`，稍等几秒再查一次。

---

## 5. 提问

1. 找到 `POST /datasets/{dataset_id}/chat`。
2. `dataset_id` 填你的编号。
3. 在 `question` 里用中文写问题。
4. 点 **Execute**。

返回结果里：

- `conclusion`：人话结论
- `chart_spec`：图表数据（前端用它画图）
- `result_table`：计算后的数据表

### 可以这样问

| 问题 | 会得到 |
|---|---|
| 各区域的销售额合计是多少？ | 柱状图 + 每个区域的总额 |
| 各区域销售额趋势 | 按时间的折线图 |
| 各渠道的销售占比 | 饼图 |
| 销售额最高的区域是哪个？ | 排序结果 |
| 数量一共多少？ | 总数 |

---

## 6. 继续追问（多轮对话）

第一次提问后，会返回一个 `conversation_id`。

想接着问同一个表：

1. 再次打开 `POST /datasets/{dataset_id}/chat`。
2. 在 `conversation_id` 里填刚才那个编号。
3. 写新的问题。

这样它会记得你们之前的对话。

---

## 7. 看历史记录

- `GET /conversations`：查看你有哪些对话。
- `GET /conversations/{conversation_id}/messages`：查看某次对话的所有问题和回答。

---

## 8. 删除不需要的数据

- `DELETE /datasets/{dataset_id}`：删除一个数据集（连同它的文件）。
- `DELETE /conversations/{conversation_id}`：删除一次对话。

---

## 9. 看 AI 花了多少

打开：

- `GET /account/ai-usage`

会告诉你这个月：

- 调用了多少次 AI
- 用了多少 token
- 花了多少钱
- 还剩多少预算

## 10. 遇到提示是什么意思

| 提示 / 状态 | 是什么意思 | 怎么办 |
|---|---|---|
| `401 UNAUTHORIZED` | 没登录或登录过期 | 重新注册/登录，重新点 Authorize |
| `404 NOT_FOUND` | 没有这个数据，或不是你的数据 | 检查编号，确认是当前账号的数据 |
| `409 DATASET_NOT_READY` | 表格还没解析完 | 等几秒再问 |
| `409 EMAIL_ALREADY_REGISTERED` | 邮箱已经注册过 | 换一个邮箱 |
| `413 FILE_TOO_LARGE` | 文件太大 | 文件控制在 50MB 以内 |
| `413 DATASET_TOO_LARGE` | 行数超过限制 | 默认最多 100 万行 |
| `415 UNSUPPORTED_FILE_TYPE` | 文件格式不支持 | 只能用 CSV / XLSX / XLS |
| `422 EMPTY_FILE` | 文件是空的 | 换一个有效文件 |
| `422 ANALYSIS_PLAN_INVALID` | 问题没能被正确理解 | 换个更明确的说法 |
| `429 RATE_LIMIT_EXCEEDED` | 请求太频繁 | 稍等一会儿 |
| `429 AI_QUOTA_EXCEEDED` | 这个月的 AI 额度用完了 | 查看用量或调预算 |
| `503 AI_SERVICE_UNAVAILABLE` | AI 服务暂时不可用 | 稍后再试 |

## 11. 常用问题

### 支持什么文件？

- `.csv`
- `.xlsx`
- `.xls`

### 中文列名可以吗？

可以。比如「日期、区域、渠道、销售额、数量」都没问题。

### 一定要填 conversation_id 吗？

不是。第一次提问可以不填；想接着上次问，才需要填。

### 为什么它可能理解错问题？

当前默认是**本地演示模式**，没接真正的云端大模型。简单问题（合计、趋势、占比、排序）效果最好；复杂问题建议接入真实模型后再用。

### 我的数据安全吗？

每个账号只能看到自己的数据。别人看不到你的表格、对话和结果。

## 13. 一个完整的练习

用项目里的 `examples/sales_demo.csv`：

1. 注册账号。
2. 上传 `sales_demo.csv`，名字写「销售数据」。
3. 等状态变成 `ready`。
4. 提问：「各区域销售额合计是多少？」
5. 你会得到：柱状图数据 + 3 个区域的总额 + 一句“华东最高……”的结论。
6. 再追问：「各区域销售额趋势」，这次会得到折线图。
