# 项目介绍（简历版 · 项目经理）

## 建议写进简历的段落

主导并交付了 0 到 1 的 **AI 数据分析助手（ChatBI）** 产品，带领团队按 M0–M4 五个里程碑完成从立项、需求拆解、技术选型到上线交付的全流程。产品面向非技术用户，支持上传 CSV/Excel 后以中文自然语言提问，自动完成结构化意图识别、受控数据计算、图表生成与结论输出。后端采用 FastAPI + SQLAlchemy + Redis，前端落地为中文可视化操作台（原生 JS + 本地 ECharts），并打通注册登录、数据上传解析、多轮对话、SSE 实时进度、历史记录与用量看板等完整闭环。

作为项目经理，我负责制定迭代计划与里程碑、协调后端/前端/测试多方协作、管控风险与交付节奏；在方案上推动“模型只输出结构化分析计划、沙箱白名单执行、不执行模型生成代码”的安全设计，显著降低数据与代码注入风险；在质量上建立 Ruff + pytest + 前端 Node 测试 + E2E + CI 的完整质量门禁，累计沉淀 55+ 项自动化测试；在工程化上落地 Docker Compose 非 root/只读容器、Alembic 迁移、Prometheus 指标与成本配额告警，并输出架构、安全、运维与用户手册，保证产品可部署、可观测、可维护。

## 短版（一屏以内）

主导交付 0 到 1 的 AI 数据分析助手（ChatBI），覆盖中文自然语言问数、数据上传解析、图表与结论生成、多轮对话和用量管理全流程；统筹跨团队协作与 M0–M4 里程碑，建立“结构化计划 + 沙箱白名单执行”的安全方案，落地 FastAPI/Docker/Prometheus 工程化体系与 55+ 项自动化测试，输出架构、运维与用户文档，保障产品按期高质量上线。

## 可量化的关键结果（可按实际调整）

- 里程碑：M0 初始化 → M1 核心分析 → M2 多轮对话/SSE → M3 可观测与配额 → M4 容器安全加固，全部按期完成。
- 自动化测试：后端 55 项 + 前端逻辑 7 项，CI 覆盖 Ruff、pytest、Compose 校验与镜像构建。
- 交付物：FastAPI 后端、中文前端操作台、Docker Compose 部署、Alembic 迁移、Prometheus 指标、完整技术文档。
